# Notas de estudo

## Tema: Git e versionamento

Git é um sistema de controle de versão que permite registrar mudanças em arquivos e colaborar em projetos.

Principais conceitos:
- repositório: local onde o projeto é armazenado
- commit: registro de uma alteração
- branch: linha de desenvolvimento paralela
- merge: união de alterações
- push: envio para um repositório remoto

## Dica

Organizar o trabalho em commits pequenos e objetivos ajuda a manter o histórico limpo e compreensível.
