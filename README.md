# Atividade recente

Este repositório foi criado para gerar atividade recente no perfil com commits reais e arquivos simples de estudo/notes.

## Objetivo

- Registrar pequenas anotações diárias
- Explorar conceitos básicos de programação e Git
- Manter histórico de commits visível no GitHub

## Seção de estudos

### Fundamentos de JavaScript

- Variáveis e tipos de dados
- Funções e escopo
- Condicionais e laços
- Arrays e objetos
- DOM e eventos (quando aplicável)

### Git e GitHub

- Repositório, commit, branch e merge
- Pull request e revisão de código
- README como documentação do projeto
- Versionamento como registro de evolução
